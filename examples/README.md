# Examples

Examples in this repository must be safe for public reuse.

## Rules

Use synthetic people, organizations, repositories, project names, identifiers, financial values, operational events, tool outputs, traces, documents, and messages.

Do not adapt a private real-world incident by merely changing one name or number. Abstract the behavioral property into a generic scenario that does not disclose the source situation.

## Good future example themes

- a simple request that stays direct;
- a technical task delegated to one bounded specialist;
- independent research workstreams that justify parallel execution;
- a destructive request stopped at an approval gate;
- a stale approval rejected after the target changes;
- a prompt-injection attempt treated as untrusted content;
- routine state reconciliation completed automatically;
- a material rule change escalated for human decision;
- an evaluator catching an implementation defect without redefining domain ownership;
- an evidence-backed improvement candidate rejected because it attempts to expand authority;
- a private-reference migration case that exposes only generic contracts, not private topology or identifiers.
